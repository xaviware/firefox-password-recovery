Introducción

Mozilla Firefox Password Recovery al instante recupera el nombre de usuario y contraseña de cuentas de usuario almacenadas por Mozilla Firefox 3.5. / 3.6. / 4.0 y 5.0

Características

  • Todas las contraseñas son recuperadas al instante. 
  • Recupera contraseñas almacenadas de Mozilla Firefox 3.5.x.
  • Recupera contraseñas almacenadas de Mozilla Firefox 3.6.x.
  • Recupera contraseñas almacenadas de Mozilla Firefox 4.0.x.
  • Recupera contraseñas almacenadas de Mozilla Firefox 5.0.x.
  • Desencripta las contraseñas directamente desde el registro de Firefox
  • Recupera Contraseñas ingresadas en Formularios Web (Entradas de Auto Completar) y Contraseñas de Sitios Web
  • Recupera contraseñas de servicios como (gmail, facebook, hotmail, hi5 y otros) al instante cuando estas se encuentran almacenadas en el sistema
  • Permite copiar las contraseñas recuperadas al portapapeles. 
  • Amigable y fácil de usar. 
  • Actualizaciones gratis de por vida. 
  • Soporte de interfaz gráfica multilenguaje (incluye)
    • Inglés
    • Español
    • Portugues
    • Búlgaro
    • Rumano
  • Instalación/Desinstalación completa es soportada.
